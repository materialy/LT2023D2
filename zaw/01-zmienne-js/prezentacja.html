Czy ta nazwa zmiennej jest poprawna?

Wpisz nazwę, a sprawdzę ją tak jak JavaScript.

Zasady: litery, cyfry, _ i $; nie od cyfry; bez spacji i myślnika; nie słowo kluczowe. Wielkość liter ma znaczenie.

Oceń sam: poprawna czy błędna?

Template literals: tekst z wstawkami

Backtick ` (klawisz pod Esc) i ${…} wstawiają wartość wprost do tekstu. Zmień dane i porównaj wyniki.

console.log("Kot " + imie + " ma " + wiek + " lata.");
console.log(`Kot ${imie} ma ${wiek} lata.`);
console.log(`Za rok: ${wiek + 1}`);
console.log('Kot ${imie}');

Przewidź wynik

const a = 2;
console.log(`${a} + ${a} = ${a + a}`);

prompt zawsze daje tekst

prompt zwraca to, co wpisał użytkownik, jako string. Po „Anuluj” zwraca null.

const odp = prompt("Ile masz lat?");
console.log(typeof odp);
console.log(odp + 1);
console.log(Number(odp) + 1);

Co trafi do konsoli?

Użytkownik wpisał 4. Program wykonuje console.log(odp * 3).

Do zapamiętania

  • <script src="index.js"></script> przed </body> podłącza plik JS.
  • console.log pisze do konsoli (F12), tam widać też błędy.
  • const to wybór domyślny; let, gdy wartość ma się zmieniać.
  • Przypisanie do const kończy się błędem TypeError.
  • Nazwy: nie od cyfry, bez spacji i myślnika, nie słowo kluczowe; piszemy camelCase.
  • `Tekst ${wyrazenie}` wstawia wartość do tekstu; w apostrofach to nie działa.
  • prompt zwraca tekst albo null; liczbę daje Number().
  • "5" + 1 to "51", a "5" * 1 to 5.
