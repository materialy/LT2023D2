Instrukcja
warunkowa if

if (wiek < 6) { cenaBiletu = 0; }

Program przestaje być listą poleceń i zaczyna podejmować decyzje. Przykład z lekcji: cena biletu zależna od wieku pasażera.

Sterowanie: strzałki ← →, spacja lub przyciski na dole.

Co powtórzymy

Kliknij temat, aby do niego przejść.

Kasa biletowa: wygrywa pierwszy prawdziwy warunek

Warunki sprawdzane są od góry. Wylosuj pasażera, zgadnij cenę, a potem zobacz, którą drogą poszedł program.

if (wiek < 6) {
cenaBiletu = 0;
} else if (wiek < 12) {
cenaBiletu = 3;
} else if (wiek < 18) {
cenaBiletu = 4;
} else {
cenaBiletu = 6;
}

Ułóż warunki we właściwej kolejności

Ktoś pomieszał gałęzie. Przesuwaj je strzałkami, aż każdy pasażer dostanie dobrą cenę.

Zasada: węższy warunek (mniejsza grupa) musi stać wyżej.

Do zapamiętania

  • if (warunek) { … } wykonuje blok tylko, gdy warunek jest prawdziwy.
  • W łańcuchu else if wygrywa pierwszy prawdziwy warunek, reszta jest pomijana.
  • Węższy warunek stawiamy wyżej (< 6 przed < 12 przed < 18).
  • else nie ma warunku i łapie całą resztę.
  • Porównujemy przez === i !==; = to przypisanie.
  • "5" === 5 to false, dlatego wynik prompt zamieniamy przez Number().
  • &&: oba warunki, ||: choć jeden, !: odwrócenie.
