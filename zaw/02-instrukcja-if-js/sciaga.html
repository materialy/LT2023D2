Zanim zaczniesz

  • Zmienną, której wartość się zmieni, tworzysz przez let, a stałą przez const.
  • prompt zwraca tekst; liczbę dostaniesz przez Number(prompt(…)).
  • Wynik sprawdzasz w konsoli przeglądarki: console.log i F12.
  • Wartość wstawisz do tekstu szablonem `Cena: ${cena} zł`.

Instrukcja if pozwala programowi wybrać drogę: fragment kodu wykona się tylko wtedy, gdy warunek jest prawdziwy. Z else if i else zbudujesz wybór z wielu możliwości, np. cenę biletu zależną od wieku.

01if, else if, else

const wiek = Number(prompt("Podaj wiek pasażera"));
let cenaBiletu;                 // wartość nadamy w jednej z gałęzi

if (wiek < 6) {                // warunek w nawiasach okrągłych
    cenaBiletu = 0;           // blok w klamrach
} else if (wiek < 12) {      // tu już wiadomo, że wiek >= 6
    cenaBiletu = 3;
} else if (wiek < 18) {
    cenaBiletu = 4;
} else {                       // wszyscy pozostali, bez warunku
    cenaBiletu = 6;
}
console.log(`Cena biletu: ${cenaBiletu} zł`);

Od góry do dołu

Warunki są sprawdzane po kolei. Wykona się tylko pierwszy prawdziwy, reszta jest pomijana.

else jest opcjonalne

else nie ma warunku i łapie wszystko, czego nie złapały gałęzie wyżej. Bez else może nie wykonać się nic.

02Operatory porównania

Porównanie daje wartość logiczną: true albo false.

operatorznaczenieprzykładwynik
===równe (wartość i typ)5 === 5true
!==różne5 !== "5"true
< >mniejsze, większe12 < 6false
<= >=mniejsze lub równe, większe lub równe18 >= 18true
==równe po zamianie typów (unikamy)"5" == 5true

W JavaScript porównujemy przez ===. Operator == najpierw zamienia typy i bywa zaskakujący.

04Typowe błędy

  • if (wiek = 18): pojedyncze = przypisuje 18, więc warunek jest zawsze prawdziwy. Porównanie to ===.
  • if (wiek < 18) … else if (wiek < 12): druga gałąź nigdy się nie wykona, bo każde dziecko złapie już pierwszy warunek. Węższy warunek dajemy wyżej.
  • else (wiek >= 65) {: else nie ma warunku, to błąd składni. Potrzebne else if.
  • prompt bez Number(): "18" === 18 to false.

06Sprawdź się

Odpowiedz w myślach, potem rozwiń.

Ile bloków najwyżej wykona się w łańcuchu if / else if / else?

Dokładnie jeden: pierwszy, którego warunek jest prawdziwy (albo else).

Czym różni się === od ==?

=== porównuje wartość i typ. == najpierw zamienia typy, więc "5" == 5 daje true.

Kiedy a || b jest fałszem?

Tylko wtedy, gdy oba warunki są fałszywe.

Co daje !(wiek >= 18) dla wiek = 20?

false: 20 >= 18 to prawda, a ! ją odwraca.

Czy po if zawsze musi być else?

Nie. Bez else przy fałszywym warunku program po prostu przechodzi dalej.

trudniejsze Kod: if (wiek < 18) cena = 4; else if (wiek < 6) cena = 0;. Ile zapłaci 3-latek?

4 zł. 3 < 18 to prawda, więc wykona się pierwsza gałąź, a wiek < 6 nie będzie już sprawdzane. Trzeba zamienić kolejność.

trudniejsze Znajdź błąd: const w = prompt("Wiek?"); if (w === 18) console.log("18!");

prompt zwraca tekst "18", a "18" === 18 to fałsz. Trzeba Number(prompt(…)).

trudniejsze Co da 0 < wiek < 6 dla wiek = 40?

true! Najpierw 0 < 40 daje true, potem true < 6 zamienia true na 1, a 1 < 6. Poprawnie: wiek > 0 && wiek < 6.
