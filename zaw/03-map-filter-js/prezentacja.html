Tablice:
map i filter

[1, 2, 3].map(x => x ** 2)

Zamiast ręcznie przechodzić po tablicy, mówimy, co zrobić z każdym elementem. Przykłady jak z lekcji: kwadraty liczb i wybieranie pełnoletnich.

Sterowanie: strzałki ← →, spacja lub przyciski na dole.

Co powtórzymy

Kliknij temat, aby do niego przejść.

Tablica: elementy i indeksy

Każdy element ma numer miejsca, czyli indeks. Liczymy od 0. Kliknij element albo wpisz indeks.

const wieki = [18, 12, 25, 19, 7];

Przewidź

Co zwróci wieki.length?

Co zwróci wieki[wieki.length - 1]?

)

Czy działa tak samo jak x => x * 2?

map: z każdego elementu robi nowy

Wybierz funkcję i przepuść elementy przez map jeden po drugim.

const tablica = [1, 2, 3, 4, 5];
const wynik = tablica.map();
console.log(wynik);

filter: zostawia elementy, dla których warunek to true

Wybierz warunek i sprawdzaj elementy po kolei. Wynik może być krótszy niż oryginał.

const wieki = [18, 12, 25, 19, 7];
const wynik = wieki.filter();
console.log(wynik);

Przewidź wynik

Wpisz, co wypisze console.log, np. [1, 2, 3]. Nawiasy i spacje możesz pominąć.

Do zapamiętania

  • Indeksy tablicy liczymy od 0; ostatni element to t[t.length - 1].
  • Funkcja strzałkowa: parametr => wynik; z klamrami potrzebny jest return.
  • map zwraca nową tablicę tej samej długości z przekształconymi elementami.
  • filter zwraca nową tablicę z elementami, dla których funkcja dała true.
  • Oryginalna tablica zostaje bez zmian, wynik trzeba przypisać do zmiennej.
  • Potęga to **, nie ^.
  • Metody można łączyć: t.filter(…).map(…); kolejność ma znaczenie.
