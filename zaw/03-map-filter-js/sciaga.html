Zanim zaczniesz

  • Stałą tworzysz przez const, a wynik wypisujesz w konsoli przez console.log.
  • Porównania (>=, <, ===) dają true albo false.
  • === porównuje, a pojedyncze = przypisuje wartość.
  • Wartość wstawisz do tekstu szablonem `${…}`.

Metody map i filter przechodzą po całej tablicy za Ciebie. map zmienia każdy element, filter zostawia tylko te, które spełniają warunek. Obie zwracają nową tablicę, oryginał zostaje bez zmian.

02Funkcja strzałkowa

Metodom map i filter podajemy funkcję, którą wywołają dla każdego elementu. Najkrócej zapisuje się ją strzałką: parametr => wynik.

Krótka forma

x => x ** 2
Wynik po strzałce jest zwracany automatycznie. ** to potęgowanie.

Forma z klamrami

x => { return x ** 2; }
Z klamrami trzeba napisać return, inaczej funkcja zwróci undefined.

03map i filter w praktyce

const tablica = [1, 2, 3, 4, 5];
// map: z każdego elementu robi nowy element
const kwadraty = tablica.map(element => element ** 2);
console.log(kwadraty);     // [1, 4, 9, 16, 25]

const wieki = [18, 12, 25, 19, 7];
// filter: zostawia elementy, dla których funkcja zwróci true
const dorosli = wieki.filter(wiek => wiek >= 18);
console.log(dorosli);      // [18, 25, 19]
console.log(wieki);        // [18, 12, 25, 19, 7], oryginał bez zmian

// łańcuch: najpierw wybierz, potem przekształć
const ceny = [12, 45, 8, 30];
const zDostawa = ceny.filter(c => c > 10).map(c => c + 5);
console.log(zDostawa);     // [17, 50, 35]

04Typowe błędy

  • t.map(x => { x * 2 }): klamry bez return dają [undefined, …].
  • wieki.filter(w => w = 18): = przypisuje, wynik 18 liczy się jak prawda, więc przejdą wszystkie elementy.
  • x ^ 2 to nie potęga (to operacja na bitach). Kwadrat to x ** 2.
  • tablica.map(…) bez przypisania wyniku: nowa tablica przepada, a oryginał się nie zmienia.

06Sprawdź się

Odpowiedz w myślach, potem rozwiń.

Co zwróci [3, 6, 9].map(x => x / 3)?

[1, 2, 3].

Co zwróci [5, 12, 8].filter(x => x > 10)?

[12]: tablicę z jednym elementem, nie samą liczbę.

Tablica ma 7 elementów. Ile elementów będzie miał wynik map?

Zawsze 7. map niczego nie pomija.

Jak dostać się do ostatniego elementu tablicy t, nie znając jej długości?

t[t.length - 1], bo indeksy kończą się na długości minus 1.

Czy po wieki.filter(…) tablica wieki jest krótsza?

Nie. filter zwraca nową tablicę, oryginał zostaje bez zmian.

trudniejsze Co wypisze console.log([1, 2, 3].map(x => x > 1))?

[false, true, true]. map zapisuje wynik funkcji, tu wynik porównania, a nie wybiera elementów.

trudniejsze Znajdź błąd: const parzyste = liczby.map(x => x % 2 === 0); (chcemy tylko liczby parzyste; % to reszta z dzielenia)

Do wybierania służy filter. map zwróci tablicę true/false. Poprawnie: liczby.filter(x => x % 2 === 0).

trudniejsze Porównaj dla [1, 2, 3, 4]: .map(x => x * 10).filter(x => x > 2) oraz .filter(x => x > 2).map(x => x * 10).

Pierwsze: [10, 20, 30, 40], bo po mnożeniu każda liczba jest większa od 2. Drugie: [30, 40]. Kolejność metod zmienia wynik.

07Spróbuj sam

  1. Pobierz index.html i tablice.js. Za pomocą map dolicz do każdej ceny 5 zł za dostawę.
    Rozwiązanie
    const zDostawa = ceny.map(cena => cena + 5);
// [17, 50, 13, 35, 10]
  2. Za pomocą filter wybierz z tablicy wieki osoby niepełnoletnie.
    Rozwiązanie
    const niepelnoletni = wieki.filter(wiek => wiek < 18);
// [12, 7, 16]
  3. Z tablicy imiona wybierz imiona dłuższe niż 6 liter i zamień je na wielkie litery.
    Podpowiedź

    Tekst też ma .length (liczba znaków), a imie.toUpperCase() zwraca tekst wielkimi literami. Połącz filter i map w łańcuch.

    Rozwiązanie
    const dlugie = imiona.filter(imie => imie.length > 6).map(imie => imie.toUpperCase());
// ["FILEMON", "BONIFACY", "MRUCZEK"]
