Wywołaj sam

Za każdym wywołaniem argument trafia do parametru imie, a return oddaje gotowy tekst.

return czy console.log? Co trafi do zmiennej?

function a(x) { return x * 2; }
function b(x) { console.log(x * 2); }
function c() { console.log("A"); return 1; console.log("B"); }
const wa = a(5);
const wb = b(5);
const wc = c();

najwiekszaLiczba krok po kroku

function najwiekszaLiczba(tablica) {
if (tablica.length === 0) {
return null;
}
let najwieksza = tablica[0];
for (const liczba of tablica) {
if (liczba > najwieksza) {
najwieksza = liczba;
}
}
return najwieksza;
}

Przepisz na funkcję strzałkową

Krótka strzałka sama zwraca wynik: const nazwa = parametr => wynik;

1. function podwoj(x) { return x * 2; }

2. function czyPelnoletni(wiek) { return wiek >= 18; }

Przewidź wynik

const pole = (a, b) => a * b;
console.log(pole(3, 4));

Przy dwóch parametrach nawiasy wokół nich są obowiązkowe.

Do zapamiętania

  • function nazwa(parametr) { … } tworzy funkcję; nazwa(argument) ją wywołuje.
  • Parametr to nazwa w deklaracji, argument to wartość przy wywołaniu.
  • return oddaje wynik i od razu kończy funkcję.
  • Bez return funkcja zwraca undefined; console.log tylko wypisuje.
  • return null to świadomy brak wyniku, np. dla pustej tablicy.
  • for…of daje wartości tablicy; return wynik dopiero po pętli.
  • Strzałka: const f = x => x * 2;; dwa parametry w nawiasach.
