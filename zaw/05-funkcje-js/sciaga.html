Funkcje w JavaScript: parametry i return

Zanim zaczniesz

  • if wykonuje blok tylko wtedy, gdy warunek jest prawdziwy; === porównuje wartości.
  • Tablica: t[0] to pierwszy element, t.length to liczba elementów.
  • Funkcja strzałkowa x => x * 2 zwraca wynik bez słowa return.
  • Zmienną, której wartość będzie się zmieniać, tworzysz przez let.

Funkcja to nazwany kawałek kodu, który uruchamiasz wiele razy z różnymi danymi. Dane dostaje przez parametry, a wynik oddaje słowem return.

01Deklaracja i wywołanie

// deklaracja: słowo function, nazwa, parametry w nawiasach
function powitanie(imie) {
    return `Cześć, ${imie}!`;     // return oddaje wynik
}
// wywołanie: nazwa i argumenty w nawiasach
const tekst = powitanie("Filemon");
console.log(tekst);                 // Cześć, Filemon!
console.log(powitanie("Bonifacy"));  // Cześć, Bonifacy!
gdziew przykładzie
parametrw deklaracji, nazwa „pudełka” na daneimie
argumentw wywołaniu, konkretna wartość"Filemon"

02return kończy funkcję

Natychmiastowe wyjście

Po return funkcja kończy działanie. Kod niżej w tej funkcji już się nie wykona.

Bez return

Funkcja bez return zwraca undefined. Tak kończy się niedokończona funkcja z lekcji dla niepustej tablicy.

return null to celowe „brak wyniku”, np. dla pustej tablicy. console.log tylko wypisuje, nie zwraca.

03Dokończona funkcja z lekcji

function najwiekszaLiczba(tablica) {
    if (tablica.length === 0) {
        return null;                  // pusta tablica: brak wyniku
    }
    let najwieksza = tablica[0];     // start: pierwszy element
    for (const liczba of tablica) {  // po kolei każdy element
        if (liczba > najwieksza) {
            najwieksza = liczba;     // znaleźliśmy większą
        }
    }
    return najwieksza;               // dopiero po pętli
}
console.log(najwiekszaLiczba([10, 4, 20, 15, 1, 100, 2]));  // 100
console.log(najwiekszaLiczba([]));                          // null

for…of daje kolejne wartości tablicy (10, 4, 20…), a for…in dałby klucze "0", "1"… Krótsza wersja całej funkcji: Math.max(...tablica), gdzie ... rozkłada tablicę na osobne argumenty.

05Typowe błędy

  • console.log zamiast return: wynik widać w konsoli, ale const w = f(3) dostaje undefined.
  • return wewnątrz pętli: funkcja kończy się po pierwszym obrocie.
  • let najwieksza = 0: dla [-5, -2] wynik będzie 0, którego w tablicy nie ma.
  • srednia[2, 4] zamiast srednia([2, 4]): brak nawiasów okrągłych, funkcja się nie wywoła.

07Sprawdź się

Odpowiedz w myślach, potem rozwiń.

Czym różni się parametr od argumentu?

Parametr to nazwa w deklaracji (imie), argument to wartość przy wywołaniu ("Filemon").

Co się stanie z instrukcją zapisaną w funkcji zaraz po return?

Nie wykona się. return od razu kończy funkcję.

Zapisz function podwoj(x) { return x * 2; } jako funkcję strzałkową.

const podwoj = x => x * 2;

Dlaczego najwiekszaLiczba zaczyna od tablica[0], a nie od 0?

Dla tablicy samych liczb ujemnych start od 0 dałby wynik 0, którego w tablicy nie ma.

Co zwróci najwiekszaLiczba([7])?

7. Start to tablica[0] = 7, w pętli nic nie jest większe.

trudniejsze Co wypisze: function f(x) { console.log(x * 2); } const w = f(3); console.log(w);?

Najpierw 6 (wypisane w funkcji), potem undefined, bo funkcja nic nie zwraca.

trudniejsze Znajdź błąd: for (const l of t) { if (l > max) max = l; return max; }

return jest w pętli, więc funkcja kończy się po pierwszym elemencie. Trzeba go przenieść za klamrę zamykającą pętlę.

trudniejsze Porównaj, co trafi do x: for (const x in [10, 20]) i for (const x of [10, 20]).

in: teksty "0" i "1" (indeksy). of: liczby 10 i 20 (wartości).

08Spróbuj sam

  1. Pobierz index.html i funkcje.js. Dokończ funkcję najwiekszaLiczba tak, żeby dla przykładowej tablicy wypisała 100.
    Podpowiedź

    Zapamiętaj pierwszy element w let najwieksza, w pętli for…of podmieniaj go na większy, a return daj dopiero po pętli. Pełne rozwiązanie jest w ramce „Dokończona funkcja z lekcji”.

  2. Napisz funkcję srednia(tablica), która zwraca średnią liczb albo null dla pustej tablicy.
    Rozwiązanie
    function srednia(tablica) {
    if (tablica.length === 0) {
        return null;
    }
    let suma = 0;
    for (const liczba of tablica) {
        suma = suma + liczba;
    }
    return suma / tablica.length;
}
  3. Napisz funkcję strzałkową czyPelnoletni, która dla wieku zwraca true albo false, i użyj jej w filter.
    Rozwiązanie
    const czyPelnoletni = wiek => wiek >= 18;
console.log(wieki.filter(czyPelnoletni));  // [18, 25, 19]
