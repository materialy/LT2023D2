Zanim zaczniesz

  • Funkcja przyjmuje parametry, a return oddaje wynik i od razu kończy jej działanie.
  • Obiekt zapisujesz w klamrach jako pary klucz: wartość, np. { marka: "Lumo", cena: 999 }.
  • Właściwość odczytasz kropką (tv.marka) albo nawiasami (tv["marka"]).
  • null oznacza „celowo brak wartości”, a funkcja bez return zwraca undefined.
  • ! odwraca wartość logiczną: !true daje false, !false daje true.

Funkcja fabrykująca (fabryka) to zwykła funkcja, która z parametrów buduje i zwraca nowy obiekt. Zanim go zbuduje, może sprawdzić dane i dla złych zwrócić null.

01Funkcja, która zwraca obiekt

Po co fabryka?

Zamiast pisać ten sam obiekt wiele razy, wołasz createTv(…) z innymi danymi. Każde wywołanie daje nowy, osobny obiekt.

Dwa możliwe wyniki

Dobre dane: obiekt z właściwościami. Złe dane: null, czyli „telewizora nie ma”.

// fabryka telewizorów
function createTv(brand, screenSize, color) {
    const colors = ["white", "black", "silver"]; // dozwolone kolory

    // walidacja: koloru NIE ma na liście, więc kończymy od razu
    if (!colors.includes(color)) {
        return null;
    }

    // skrócony zapis: brand znaczy to samo co brand: brand
    return {
        brand,
        screenSize,
        color
    };
}

const tv1 = createTv("Lumo", 42, "black");
console.log(tv1);       // { brand: 'Lumo', screenSize: 42, color: 'black' }
console.log(tv1.brand); // Lumo

const tv2 = createTv("Lumo", 50, "pink");
console.log(tv2);       // null

02Skrócony zapis właściwości

Gdy zmienna (albo parametr) nazywa się tak samo jak klucz, wystarczy napisać nazwę raz.

Pełny zapisSkrócony zapisMożna skrócić?
{ brand: brand }{ brand }tak
{ color: color, screenSize: screenSize }{ color, screenSize }tak
{ size: screenSize }—nie, inna nazwa
{ price: 1999 }—nie, to liczba, nie zmienna

Oba zapisy można mieszać: { brand, size: screenSize, price: 1999 }.

03Sprawdzanie danych: includes i !

tablica.includes(x) zwraca true, gdy x jest w tablicy, i false, gdy go nie ma. Porównuje dokładnie jak ===.

WyrażenieWynikDlaczego
colors.includes("black")truejest na liście
colors.includes("Black")falsewielkość liter ma znaczenie
[1, 2, 3].includes("2")falsetekst "2" to nie liczba 2
!colors.includes("pink")true! odwraca false na true

Wczesny return

Sprawdzenie złych danych stoi na początku funkcji. return null kończy ją od razu, więc kod niżej wykona się tylko dla poprawnych danych. Warunków może być kilka, np. jeszcze if (screenSize < 24) return null;.

Wynik fabryki sprawdzaj przed użyciem: if (tv === null) { … } else { console.log(tv.brand); }.

04Typowe błędy

Pułapka: return i klamra w osobnych liniach

Po samym return JavaScript sam wstawia średnik. Funkcja zwraca undefined, a obiekt pod spodem jest pomijany. Klamra { musi być w tej samej linii co return.

  • if (colors.includes(color)) return null;: brak !, więc odrzucane są dobre kolory.
  • return { brand, size, color }, gdy nie ma zmiennej size: błąd ReferenceError.
  • createTv("Lumo", 50, "pink").brand: odczyt z null daje TypeError.
  • Brak return przed obiektem: funkcja zwraca undefined.

06Sprawdź się

Odpowiedz w myślach, potem rozwiń.

Jak skrócić zapis { color: color }?

{ color }. Nazwa zmiennej i klucza jest taka sama.

Co zwraca ["a", "b"].includes("c")?

false, bo w tablicy nie ma "c".

Czy dwa wywołania createTv("Lumo", 42, "black") dają ten sam obiekt?

Nie. Każde wywołanie tworzy nowy obiekt; zmiana koloru w jednym nie zmienia drugiego.

Po co w fabryce zwracać null, a nie np. pusty obiekt?

null łatwo sprawdzić (tv === null) i jasno mówi „nie utworzono”. Pusty obiekt wyglądałby jak prawdziwy telewizor bez danych.

Co zwróci createTv("Lumo", 42) (bez koloru)?

null. Brakujący parametr ma wartość undefined, a tej nie ma na liście kolorów.

trudniejsze Znajdź błąd: const size = 42; return { brand, screenSize: 42, size, colour }; przy parametrze color.

colour nie istnieje (parametr to color), więc skrócony zapis rzuci ReferenceError. Reszta jest poprawna.

trudniejsze Co wypisze kod: return w jednej linii, a { brand } w następnej, potem console.log(createTv("Lumo", 42, "black"))?

undefined. Po samym return JavaScript wstawia średnik i funkcja kończy się bez wartości.

trudniejsze Porównaj warunki !colors.includes(color) i colors.includes(color) === false.

Działają tak samo, bo includes zawsze zwraca true albo false. Zapis z ! jest krótszy.

07Spróbuj sam

  1. Pobierz fabryka.js i index.html do jednego folderu. Uzupełnij return w createTv skróconym zapisem i otwórz stronę z konsolą (F12).
    Rozwiązanie
    return { brand, screenSize, color };
  2. Dodaj drugą walidację: przekątna screenSize musi mieć od 24 do 85 cali, inaczej null.
    Podpowiedź

    Połącz dwa porównania przez ||: za mała albo za duża.

    Rozwiązanie
    if (screenSize < 24 || screenSize > 85) {
    return null;
}
  3. Napisz fabrykę createPet(name, species, age): gatunek tylko z listy ["kot", "pies", "chomik"], wiek co najmniej 0. Dla złych danych null.
    Rozwiązanie
    function createPet(name, species, age) {
    const gatunki = ["kot", "pies", "chomik"];
    if (!gatunki.includes(species) || age < 0) {
        return null;
    }
    return { name, species, age };
}
  4. Utwórz tablicę kilku zwierząt (w tym jedno z błędnymi danymi) i usuń z niej null metodą filter.
    Rozwiązanie
    const zwierzeta = [
    createPet("Filemon", "kot", 3),
    createPet("Pikuś", "krokodyl", 2)
];
const poprawne = zwierzeta.filter(z => z !== null);
console.log(poprawne); // tylko Filemon
