Właściwość czy metoda?

Obiekt opisuje rzecz: ma cechy (właściwości) i czynności (metody). Klikaj kafelek, aż pokaże dobrą grupę, potem sprawdź.

cecha to rzeczownik, czynność to czasownik

Jak wygląda metoda

Metoda to właściwość, której wartością jest funkcja. Kliknij linijkę, żeby zobaczyć objaśnienie.

Kto jest this?

this to obiekt przed kropką w wywołaniu. Przewidź, co wypisze każde wywołanie.

let mobile1 = {
brand: 'Lumo',
getInfo() { console.log(this.brand); }
};
let mobile2 = { brand: 'Nokto', getInfo: mobile1.getInfo };
let mobile3 = { brand: 'Fiko',
getInfo: () => console.log(this.brand) };

mobile2 pożycza metodę od mobile1

wywołanieco wypisze?wynik
mobile1.getInfo()
mobile2.getInfo()
mobile3.getInfo()
mobile1.brand = 'Lumo Pro';
mobile1.getInfo()

Metoda zmienia obiekt

Przez this metoda może zmienić dane obiektu, czyli jego stan. Najpierw przewidź wynik, potem sprawdź krok po kroku.

let mobile1 = {
battery: 40,
useBattery(amount = 10) {
this.battery = this.battery - amount;
},
charge() {
this.battery = 100;
}
};
mobile1.useBattery();
mobile1.useBattery(25);
mobile1.charge();
mobile1.useBattery();
console.log(mobile1.battery);

Do zapamiętania

  • Właściwość to cecha obiektu (dana), metoda to czynność (funkcja w obiekcie).
  • Pełny zapis: call: function (contact) { … }, skrócony: call(contact) { … }.
  • Właściwości i metody rozdzielamy przecinkami.
  • Wywołanie zawsze z nawiasami: mobile1.getInfo().
  • this w metodzie to obiekt przed kropką w wywołaniu.
  • Bez this. JavaScript szuka zwykłej zmiennej i zgłasza błąd.
  • Parametr domyślny (contact = 'Kot Filemon') działa, gdy brak argumentu.
  • Funkcja strzałkowa nie ma własnego this, więc nie pisz nią metod.
  • console.log wypisuje, return oddaje wynik do dalszego użycia.
