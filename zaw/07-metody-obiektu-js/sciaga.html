Zanim zaczniesz

  • Obiekt zapisujesz w klamrach jako pary klucz: wartość, oddzielone przecinkami.
  • Właściwość odczytasz kropką (mobile1.brand) albo nawiasami (mobile1["brand"]).
  • Funkcja przyjmuje parametry, a return oddaje wynik i od razu kończy jej działanie.
  • Funkcja bez return zwraca undefined.
  • Wartość wstawisz do tekstu szablonem `Marka: ${brand}`.

Obiekt w JavaScript przechowuje dane, ale może też mieć czynności. Taka czynność to metoda, czyli funkcja zapisana wewnątrz obiektu. W metodzie słowo this oznacza obiekt, na którym ją wywołano.

01Właściwości i metody

W programowaniu obiektowym obiekt opisuje jakąś rzecz, np. telefon, postać z gry albo zamówienie. Ma cechy i czynności.

Właściwość: co obiekt ma

Dana: tekst, liczba, tablica. Telefon ma brand, model, memorySize.

Metoda: co obiekt umie

Funkcja w obiekcie. Telefon umie call(), sendSms(), getInfo(). Nazwę metody zwykle zaczynamy od czasownika.

02Jak zapisać i wywołać metodę

// obiekt opisuje telefon (dane fikcyjne)
let mobile1 = {
    brand: 'Lumo',
    model: 'Lumo X5',
    memorySize: '256 GB',
    battery: 40,

    // metoda = właściwość, której wartością jest funkcja
    call: function (contact = 'Kot Filemon') {
        console.log(`Calling ${contact}`);
    },

    // skrócony zapis: bez dwukropka i bez słowa function
    sendSms(message) {
        console.log(`Message: "${message}" was sent`);
    },

    // this = obiekt, na którym wywołano metodę
    getInfo() {
        console.log(`Brand: ${this.brand}, Model: ${this.model}`);
    },

    // metoda może zwrócić tekst zamiast go wypisać
    getMemorySize() {
        return `Wielkość pamięci: ${this.memorySize}`;
    },

    // metoda może zmienić dane obiektu (jego stan)
    charge() {
        this.battery = 100;
    }
};

mobile1.call();                       // Calling Kot Filemon
mobile1.call('Jan Testowy');          // Calling Jan Testowy
mobile1.sendSms('Hej!');             // Message: "Hej!" was sent
mobile1.getInfo();                    // Brand: Lumo, Model: Lumo X5
console.log(mobile1.getMemorySize()); // Wielkość pamięci: 256 GB
mobile1.charge();
console.log(mobile1.battery);         // 100

Metody i właściwości rozdzielamy przecinkiem, tak jak pary klucz: wartość.

03this, czyli „ten obiekt”

Po co this?

this.brand w metodzie znaczy „marka obiektu, który mnie wywołał”. Przy mobile1.getInfo() this to mobile1.

Zawsze aktualne dane

Gdy zmienisz mobile1.brand, kolejne getInfo() pokaże już nową markę, bo this czyta dane w chwili wywołania.

Pułapka: funkcja strzałkowa

Funkcja strzałkowa nie ma własnego this. Metoda getInfo: () => console.log(this.brand) nie zobaczy marki telefonu (w zwykłym skrypcie wypisze undefined). Metody pisz przez function albo skrócony zapis.

04Wypisać czy zwrócić?

Gdy polecenie mówi „zwróci komunikat”, sprawdź, czy chodzi o wypisanie w konsoli, czy o return. Wynik z return możesz zapisać w zmiennej i użyć dalej.

05Typowe błędy

  • ${brand} zamiast ${this.brand}: błąd brand is not defined.
  • mobile1.getInfo; bez nawiasów: metoda się nie wykona, nic się nie wypisze.
  • Brak przecinka po właściwości przed metodą: SyntaxError.
  • console.log(mobile1.getInfo()), gdy getInfo tylko wypisuje: po tekście pojawi się undefined.

07Sprawdź się

Odpowiedz w myślach, potem rozwiń.

Czym różni się właściwość od metody?

Właściwość przechowuje daną (tekst, liczbę, tablicę). Metoda to funkcja, czyli coś, co obiekt umie zrobić.

Jak wywołać metodę sendSms obiektu mobile1 z tekstem „Cześć”?

mobile1.sendSms('Cześć');

Co wypisze mobile1.call('Jan Testowy'), skoro parametr ma wartość domyślną 'Kot Filemon'?

Calling Jan Testowy. Wartość domyślna działa tylko wtedy, gdy nie podasz argumentu.

Ile metod ma obiekt { a: 1, b() {}, c: function () {} }?

Dwie: b i c. a to zwykła właściwość z liczbą.

Dlaczego w metodzie piszemy this.brand, a nie mobile1.brand?

this działa dla każdego obiektu, który ma tę metodę, i nie psuje się po zmianie nazwy zmiennej.

trudniejsze Co wypisze: const o = { n: 'A', show() { console.log(this.n) } }; o.n = 'B'; o.show();

B. this czyta wartość w chwili wywołania, a wtedy n jest już równe 'B'.

trudniejsze Znajdź błąd: getInfo: function { console.log(this.brand) }

Brakuje nawiasów po function: ma być function () { … }, nawet gdy nie ma parametrów.

trudniejsze Porównaj mobile1.getMemorySize i mobile1.getMemorySize().

Bez nawiasów dostajesz samą funkcję i nic się nie dzieje. Z nawiasami metoda się wykonuje i zwraca tekst „Wielkość pamięci: 256 GB”.

08Spróbuj sam

  1. Pobierz index.html i hero.js do jednego folderu. Otwórz index.html w przeglądarce, a konsolę przez F12. W hero.js dopisz metodę introduce(), która wypisze „Jestem Rycerz Bajtek, poziom 1, życie 100”, korzystając z this.
    Rozwiązanie
    introduce() {
    console.log(`Jestem ${this.name}, poziom ${this.level}, życie ${this.hp}`);
},
  2. Dopisz metodę levelUp(): zwiększa level o 1 i wypisuje „Awans! Poziom 2”.
    Podpowiedź

    Zmień właściwość przez this: this.level = this.level + 1; albo this.level++;.

    Rozwiązanie
    levelUp() {
    this.level++;
    console.log(`Awans! Poziom ${this.level}`);
},
  3. Dopisz takeDamage(amount = 10): odejmuje amount od hp. Gdy hp spadnie do 0 lub niżej, ustawia hp na 0 i wypisuje „Koniec gry”, w przeciwnym razie „Zostało 90 punktów życia”. Odkomentuj wywołania na dole pliku i sprawdź wyniki.
    Rozwiązanie
    takeDamage(amount = 10) {
    this.hp = this.hp - amount;
    if (this.hp <= 0) {
        this.hp = 0;
        console.log('Koniec gry');
    } else {
        console.log(`Zostało ${this.hp} punktów życia`);
    }
}
