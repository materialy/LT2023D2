Dodawanie: push i length

Wypisywanie listy krok po kroku

Najpierw sprawdzamy, czy lista jest pusta. Potem forEach wykonuje funkcję dla każdego elementu po kolei.

showAnimals() {
if (this.animals.length === 0) {
console.log('W schronisku nie ma zwierząt');
return;
}
this.animals.forEach(animal => {
console.log(`${animal.name} (${animal.species})`);
});
}

Do zapamiętania

  • Do danych idziemy po kolei: shelter.animals[1].species.
  • Indeksy liczymy od 0, ostatni element ma indeks length - 1.
  • push({ name, species }) dopisuje jeden obiekt na koniec listy.
  • W metodzie zawsze this.animals, nie samo animals.
  • Pustą listę rozpoznajesz po length === 0, nigdy po === [].
  • forEach wykonuje coś dla każdego elementu i nic nie zwraca.
  • filter zwraca nową tablicę, gdy nic nie pasuje, zwraca [].
  • W warunku filter porównujesz przez ===, a nie =.
  • „Zwróć liczbę” oznacza return this.animals.length.
  • Czyszczenie: this.animals = [] albo this.animals.length = 0.
