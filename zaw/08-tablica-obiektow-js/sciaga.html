Zanim zaczniesz

  • Metodę zapisujesz w obiekcie jak funkcję, a do jego danych sięgasz przez this, np. this.name.
  • filter zwraca nową tablicę z elementami, dla których funkcja zwróciła true.
  • Skrócony zapis { name, species } tworzy właściwości o nazwach i wartościach zmiennych.
  • t.length to liczba elementów tablicy, a t[0] to pierwszy element.
  • return oddaje wynik, a console.log tylko go wypisuje.

Obiekt może przechowywać tablicę innych obiektów, np. schronisko i jego zwierzęta. Metody takiego obiektu dodają elementy, wypisują je, wyszukują, liczą i czyszczą listę.

03Pełny przykład

const shelter = {
    name: 'Schronisko Pod Lipą',
    animals: [],                           // na start pusta lista

    addAnimal(name, species) {
        const animal = { name, species };    // nowy obiekt zwierzęcia
        this.animals.push(animal);          // dopisz na koniec
    },

    showAnimals() {
        if (this.animals.length === 0) {
            console.log('W schronisku nie ma zwierząt');
            return;                         // koniec metody
        }
        this.animals.forEach(animal => {
            console.log(`${animal.name} (${animal.species})`);
        });
    },

    showBySpecies(species) {
        const found = this.animals.filter(animal => animal.species === species);
        found.forEach(animal => console.log(animal.name));
    },

    getNumAnimals() {
        return this.animals.length;          // zwraca, nie wypisuje
    },

    resetAnimals() {
        this.animals = [];                   // nowa, pusta tablica
    }
};

shelter.addAnimal('Filemon', 'kot');
shelter.addAnimal('Burek', 'pies');
shelter.addAnimal('Mruczek', 'kot');
shelter.showAnimals();                // Filemon (kot), Burek (pies), Mruczek (kot)
shelter.showBySpecies('kot');         // Filemon, Mruczek
console.log(shelter.getNumAnimals()); // 3
shelter.resetAnimals();
console.log(shelter.getNumAnimals()); // 0
shelter.showAnimals();                // W schronisku nie ma zwierząt

04Typowe błędy

Pułapka: === []

this.animals === [] daje zawsze false, nawet dla pustej listy. Każde [] to nowa, osobna tablica, a === sprawdza, czy to ta sama tablica. Pustą listę rozpoznasz po length === 0.

  • animals.push(…) bez this.: błąd animals is not defined.
  • push(name, species): dodaje dwa osobne napisy zamiast jednego obiektu.
  • filter(a => a.species = species): pojedyncze = nadpisuje gatunek każdego zwierzęcia i wybiera wszystkie.
  • let animals = [] w metodzie: tworzy nową zmienną lokalną, a lista obiektu zostaje bez zmian.

05Słowniczek

tablica obiektów
tablica, której elementami są obiekty o tych samych kluczach, np. zwierzęta z name i species
indeks
numer elementu w tablicy, liczony od 0
push
metoda tablicy, która dopisuje element na koniec
length
liczba elementów tablicy; pusta tablica ma length równe 0
forEach
metoda tablicy, która wykonuje funkcję dla każdego elementu po kolei i nic nie zwraca
filter
metoda tablicy, która zwraca nową tablicę z elementami spełniającymi warunek
skrócony zapis właściwości
{ name, species } to to samo co { name: name, species: species }
wczesny return
return; w środku metody, który kończy ją od razu, np. gdy lista jest pusta
zmienna lokalna
zmienna utworzona w metodzie przez let lub const; znika po zakończeniu metody

06Sprawdź się

Odpowiedz w myślach, potem rozwiń.

Jak odczytać gatunek pierwszego zwierzęcia ze schroniska?

shelter.animals[0].species: obiekt, tablica, indeks, właściwość.

Jak dodać kota Mruczka bez metody addAnimal?

shelter.animals.push({ name: 'Mruczek', species: 'kot' });

Czym różni się forEach od filter?

forEach tylko wykonuje coś dla każdego elementu i zwraca undefined. filter zwraca nową tablicę z wybranymi elementami.

Po co getNumAnimals() ma return, skoro można wypisać liczbę?

Zwrócony wynik można dalej wykorzystać, np. if (shelter.getNumAnimals() > 10). Wypisanej liczby program nie użyje.

Czy w showAnimals() return po komunikacie o pustej liście jest konieczny?

Tutaj nie, bo forEach na pustej tablicy nic nie zrobi. Ale return wyraźnie kończy metodę i chroni, gdy pod spodem dopiszesz inny kod, np. nagłówek „Lista zwierząt:”.

trudniejsze Co wypisze console.log([] === [])?

false. To dwie różne tablice, choć obie puste. Dlatego pustą listę sprawdzamy przez length.

trudniejsze Znajdź błąd: showBySpecies(species) { this.animals.filter(a => a.species === species); }

Wynik filter nigdzie nie trafia: nie jest zapisany ani wypisany. Trzeba go zapisać w zmiennej i wypisać, np. forEach.

trudniejsze Porównaj this.animals = [] i this.animals.length = 0.

Oba dają pustą listę. Pierwszy podstawia nową tablicę, drugi opróżnia tę samą. Różnicę widać tylko wtedy, gdy inna zmienna wskazuje starą tablicę.

07Spróbuj sam

  1. Pobierz index.html i playlist.js do jednego folderu, otwórz index.html i konsolę (F12). Napisz addSong(title, artist) i showSongs() z komunikatem „Playlista jest pusta”.
    Rozwiązanie
    addSong(title, artist) {
    this.songs.push({ title, artist });
},
showSongs() {
    if (this.songs.length === 0) {
        console.log('Playlista jest pusta');
        return;
    }
    this.songs.forEach(song => console.log(`${song.title} - ${song.artist}`));
},
  2. Napisz showByArtist(artist), która wypisze tylko tytuły piosenek podanego wykonawcy.
    Podpowiedź

    Najpierw filter z warunkiem song.artist === artist, potem forEach na wyniku.

    Rozwiązanie
    showByArtist(artist) {
    const found = this.songs.filter(song => song.artist === artist);
    found.forEach(song => console.log(song.title));
},
  3. Napisz getNumSongs() (zwraca liczbę przez return) i clearSongs(). Odkomentuj wywołania na dole pliku: liczby powinny wyjść 3 i 0.
    Rozwiązanie
    getNumSongs() {
    return this.songs.length;
},
clearSongs() {
    this.songs = [];
}
  4. Dla chętnych: dopisz removeSong(title), która usunie piosenkę o podanym tytule.
    Podpowiedź

    Zostaw w tablicy wszystkie piosenki o innym tytule: this.songs = this.songs.filter(song => song.title !== title);
